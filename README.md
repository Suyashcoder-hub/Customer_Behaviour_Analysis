# 🛍️ Customer Shopping Behavior Analysis

An end-to-end **Data Analytics project** that analyzes customer shopping behavior using **Python, PostgreSQL, SQL, and Power BI**.

The project works with transactional data containing **3,900 customer purchases across multiple product categories** to identify spending patterns, customer segments, product preferences, discount behavior, subscription trends, and revenue contribution.

---

## 📌 Project Overview

The main objective of this project is to transform raw customer transaction data into meaningful business insights that can support better decision-making.

The project follows a complete analytics workflow:

**Raw Dataset → Data Cleaning & EDA → Feature Engineering → PostgreSQL → SQL Analysis → Power BI Dashboard → Business Recommendations**

---

## 🎯 Objectives

* Analyze customer purchasing behavior
* Understand revenue contribution across customer segments
* Identify top-performing products and categories
* Compare subscribers and non-subscribers
* Analyze the impact of discounts on purchasing behavior
* Segment customers based on purchase history
* Analyze purchasing behavior across age groups
* Compare shipping methods and spending
* Build an interactive Power BI dashboard
* Generate actionable business recommendations

## 🔄 Project Workflow

### 1. Data Loading

The dataset was imported into Python using **Pandas**.

Initial analysis was performed using functions such as:

```python
df.info()
df.describe()
df.isnull().sum()
```

This helped understand the dataset structure, data types, summary statistics, and missing values.

---

### 2. Data Cleaning

The following preprocessing steps were performed:

* Checked for missing values
* Handled missing `review_rating` values
* Standardized column names
* Checked data consistency
* Removed redundant columns

Missing review ratings were imputed using the **median rating of the respective product category**. Column names were also converted to **snake_case** for better readability.

---

### 3. Feature Engineering

New features were created to improve the analysis.

#### Age Group

Customers were divided into different age groups using age binning.

```text
Age → Age Group
```

#### Purchase Frequency

A `purchase_frequency_days` feature was created from the available purchase data.

These engineered features helped in customer segmentation and demographic analysis.

---

### 4. Data Consistency Check

The relationship between:

* `discount_applied`
* `promo_code_used`

was examined to identify redundancy.

After the analysis, `promo_code_used` was dropped from the cleaned dataset.

---

### 5. PostgreSQL Integration

After cleaning the data in Python, the resulting DataFrame was loaded into **PostgreSQL**.

This allowed SQL to be used for structured business analysis and answering specific business questions.

---

## 🔎 SQL Business Analysis

The project answered several business questions using PostgreSQL.

### Key Analysis Performed

1. **Revenue by Gender**
   Compared revenue generated by male and female customers.

2. **High-Spending Discount Users**
   Identified customers who used discounts but still spent above the average purchase amount.

3. **Top 5 Products by Rating**
   Identified products with the highest average review ratings.

4. **Shipping Type Comparison**
   Compared average purchase amounts between Standard and Express shipping.

5. **Subscribers vs Non-Subscribers**
   Compared average spending and total revenue between subscribers and non-subscribers.

6. **Discount-Dependent Products**
   Identified products with the highest percentage of discounted purchases.

7. **Customer Segmentation**
   Classified customers into:

   * New
   * Returning
   * Loyal

8. **Top 3 Products per Category**
   Identified the most purchased products within each category.

9. **Repeat Buyers & Subscriptions**
   Analyzed whether customers with more than five purchases were more likely to subscribe.

10. **Revenue by Age Group**
    Calculated the revenue contribution of different customer age groups.
